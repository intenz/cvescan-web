External API

Commercial CPE → CVE matching for integrations. Documentation only on this page — live calls are not enabled from the website UI.

Base URL

https://api.cvescan.app/api/external

Authentication

Authorization: Bearer <api_key>

Endpoints

  • POST /match — body with cpes array or products list
  • GET /match?cpe= — match a single CPE
  • GET /cve/:cveId — CVE details (+ Nuclei link when available)
  • GET /health — health check

Privacy

Client scan files from the web product are never stored. This API reads the shared vulnerability catalog only.

Contact support@cvescan.app for API access.
