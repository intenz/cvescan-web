External API — Commercial CPE → CVE Matching

Commercial CPE to CVE matching API for integrations. Map software inventories and CPE identifiers to NVD vulnerabilities with CVSS severity. Documentation only on this page — live calls are not enabled from the website UI.

Base URL

https://api.cvescan.app/api/external

Authentication

Authorization: Bearer <api_key>

Endpoints

  • POST /match — body with cpes array or products list
  • GET /match?cpe= — match a single CPE against known CVEs
  • GET /cve/:cveId — CVE details (+ Nuclei link when available)
  • GET /health — health check

Privacy

Client scan files from the web product are never stored. This API reads the shared vulnerability catalog only — privacy-first CPE → CVE matching for production integrations.

Contact support@cvescan.app for API access.
